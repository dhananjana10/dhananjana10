## 🚀 Featured Projects

### 🛒 FreshFare — Grocery POS System

A grocery point-of-sale application focused on retail operations and management.

- Point-of-sale and inventory management workflows.
- Sales analytics and dashboard visualizations.
- Employee and supplier management functionality.
- AI chatbot integration.

**Technologies:** JavaScript, React, Node.js, Express.js, MongoDB, Chart.js.

[![View Repository](https://img.shields.io/badge/View_Repository-2F6B4F?style=for-the-badge&logo=github&logoColor=white)](https://github.com/dhananjana10/FreshFare)

### 🤖 Chatbot AI DB — AI Database Toolkit

A TypeScript library designed to connect MongoDB-based applications with AI models for database-related workflows.

- Integration with multiple AI providers.
- AI-assisted database query workflows.
- Provider failover and caching capabilities.
- Reusable functionality for application developers.

**Technologies:** TypeScript, MongoDB, LLM APIs.

[![View Repository](https://img.shields.io/badge/View_Repository-2F6B4F?style=for-the-badge&logo=github&logoColor=white)](https://github.com/dhananjana10/chatbot-ai-db)

### 📊 Donor Availability Predictor

A machine learning project exploring the prediction of donor availability through a Python-based application.

- Machine learning model development.
- Logistic Regression experimentation.
- Interactive application using Streamlit.
- Prediction results and report generation.

**Technologies:** Python, Scikit-learn, Streamlit, Jupyter Notebook.

[![View Repository](https://img.shields.io/badge/View_Repository-2F6B4F?style=for-the-badge&logo=github&logoColor=white)](https://github.com/dhananjana10/donor-availability-predict)

### 💰 MoneyMate — Personal Finance Tracker

An Android application designed to help users track personal finances and understand their spending habits.

- Expense tracking and categorization.
- Spending analytics.
- Light and dark interface modes.
- Offline-oriented functionality.

**Technologies:** Kotlin, Android SDK, Gradle, XML.
